# 灵修笔记 iOS App · 需求说明（v1）

> 本文档记录与需求方确认过的 v1 范围，作为开发与验收依据。
> 确认日期：2026-09-27

## 1. 产品定位

一款帮助基督徒每天亲近神的**灵修笔记 App**：读经、默想、记录、祷告。
主要使用者是**教会 / 团契的弟兄姊妹**。

## 2. 平台与技术

| 项目 | 决定 |
| --- | --- |
| 平台 | 原生 iOS App，**仅 iPhone** |
| 最低系统 | iOS 17 |
| 技术栈 | Swift + SwiftUI，数据用 SwiftData；核心逻辑放在独立的 Swift Package（`DevotionCore`）里，便于测试 |
| 视觉风格 | **温暖纸张风**：米白纸张底色、暖棕/金色点缀、经文用衬线字体；支持深色模式 |
| 界面语言 | **简体中文 + 英文**（默认跟随系统，可在设置里手动切换） |

## 3. 功能范围

### 3.1 灵修笔记
- **多种模板**，每次写时可选：
  - **SOAP 灵修**：经文（Scripture）→ 观察（Observation）→ 应用（Application）→ 祷告（Prayer）
  - **自由书写**：标题 + 引用经文 + 正文
  - **感恩日记**：今日经文 + 感恩的事 + 祷告
  - **ACTS 祷告**：赞美（Adoration）→ 认罪（Confession）→ 感恩（Thanksgiving）→ 祈求（Supplication）
- 写作时可**从内置圣经中点选经文，一键引用**到笔记
- 自动保存；可修改日期（补写之前的灵修）
- 标签、全文搜索
- **日历回顾**：月历上标记有灵修的日子
- **连续灵修天数**、本月篇数等统计
- 单篇笔记可以文字形式分享

### 3.2 每日经文
- 首页每天显示一节金句（和合本 / KJV，跟随界面语言或对照显示）
- 可「换一节」、分享、直接用这节经文开始写灵修

### 3.3 内置圣经
- 内置完整**和合本（简体）**与 **KJV 钦定本**（均为公有领域）
- 按卷、章阅读，可切换：中文 / 英文 / 中英对照
- 点选一节或多节经文：复制、分享、引用到新的灵修笔记
- 记住上次读到的位置；字号可调
- 经文搜索

### 3.4 代祷事项
- 个人私密的代祷清单：事项、为谁代祷、详细内容
- 「今天已为此祷告」计数
- 标记「已蒙应允」，并写下见证；可移回代祷中
- 单条代祷可以**文字形式分享**（如发到微信群）

### 3.5 附加功能
- **每日灵修提醒**：每天定时本地通知，内容为当天的经文
- **桌面 / 锁屏小组件**：显示每日经文
- **Face ID / 密码锁**：打开 App 需要验证；切到后台时隐藏内容

### 3.6 数据
- v1 数据**保存在本机**（SwiftData）
- 支持**导出 / 导入备份文件**（JSON），以及把全部笔记导出为 Markdown
- 数据模型按 **iCloud (CloudKit) 兼容**的方式设计：以后有了付费开发者账号，打开 iCloud 能力即可多设备同步，无需改数据结构

## 4. 不在 v1 范围内

- 读经计划与打卡
- 小组共享代祷墙 / 账号登录 / 自建服务器
- iPad、Mac 适配
- NIV 等有版权的译本（不能合法内置），以及跳转外部 NIV 的按钮

## 5. 约束与说明

- **开发者账号**：暂不购买付费 Apple 开发者账号。
  - 可以用免费账号通过 Xcode 把 App 装到自己的 iPhone 上测试（每 7 天需重新安装一次）。
  - iCloud 同步、TestFlight 分发、上架 App Store **都需要付费账号**（$99/年）。要分发给弟兄姊妹时，需要由个人或教会申请。
  - 小组件只显示内置的每日经文，不依赖 App Group，免费账号也能使用。
- **经文来源**：和合本（1919，简体）与 KJV 均为公有领域文本，取自 [open-bibles](https://github.com/seven1m/open-bibles)。
